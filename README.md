# HSC Sample Atelier

Production app for [atelier.hautesoundcouture.com](https://atelier.hautesoundcouture.com), deployed as the Vercel project `hsc-deep-echo`.

## Branches

- `marketing-automation` is the canonical development and Vercel production branch.
- `main` is kept fast-forwarded to the same commit so a default checkout always contains the current Atelier source.

Do not create a replacement repository or branch for Atelier changes. Continue on `marketing-automation`, verify the Vercel deployment, then fast-forward `main` to the same verified commit.
