# HSC Sample Atelier repository instructions

- The application source is in this repository.
- Use the existing `marketing-automation` branch for all Atelier changes; it is the Vercel production branch.
- Do not create another repository or branch for Atelier work.
- After testing and pushing `marketing-automation`, verify the `hsc-deep-echo` Vercel production deployment.
- Keep `main` fast-forwarded to the same verified commit so fresh/default checkouts contain the current source.
